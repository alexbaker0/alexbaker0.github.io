How the zeros build the staircase

Riemann's explicit formula rebuilds the prime count exactly from the zeros ρ = ½ + iγ of ζ(s). The smooth term gives the trend. Each zero adds one wave that oscillates at frequency γ in log x with height about √x / (|ρ| log x). Add enough waves and a sharp step appears at every prime.

Walking up the critical strip

Fix the real part σ and let t climb. The value ζ(σ + it) traces a curve in the plane. On the critical line σ = ½ every loop that passes through the origin is a zero. Slide σ away from ½ and the loops start to miss 0: the Riemann hypothesis says they always do.

ζ(s) on the whole plane

Each point s is coloured by the value ζ(s). Hue is the argument: red is positive real, cyan negative real. Brightness is size, so zeros are dark points where every hue meets and the pole at s = 1 is the bright one. Each brightness band marks |ζ| doubling. Left of 0 the plane is reached by the functional equation.

ζ(s) = 2sπs−1 sin(πs⁄2) Γ(1−s) ζ(1−s)
Hue key: the argument of ζ(s). Going round a zero anticlockwise, colours run red → yellow → green → cyan → blue → magenta.
