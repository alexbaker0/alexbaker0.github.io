# Zeta Atlas

Explore the Riemann zeta function in three views:

1. **Prime staircase**: rebuild π(x) from the first N of 2,000 zeta zeros using Riemann's explicit formula, and watch each zero's wave add to the staircase.
2. **Up the critical strip**: trace ζ(σ + it) as t climbs and see the curve loop through the origin at each zero on σ = ½.
3. **The complex plane**: ζ(s) on the whole plane, shown by domain colouring.

Everything is computed in the browser. Live: https://alexbaker0.github.io/zeta-atlas/
